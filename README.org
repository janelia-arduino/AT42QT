** Description

Arduino library for selected Microchip AT42QT capacitive touch controllers.

Supported chips:

- =AT42QT1060=
- =AT42QT1070=
- =AT42QT2120=
- =AT42QT2160=

This library does not attempt to provide generic support for the full AT42QT
product family. Support is implemented per device, against each chip's register
map and documented behavior.

This refresh brings the repo in line with the newer library layout used in
=TCA6408=: Pixi tasks, repository-wide clang-format support, clearer metadata,
native tests, and a safer I2C core with typed errors.

* Quick Start

The preferred flow is that the sketch configures the =TwoWire= bus and then
passes that configured bus into the device instance with =setup()=.

#+BEGIN_SRC cpp
#include <AT42QT2120.h>

TwoWire &wire = Wire;
AT42QT2120 touch_sensor;

void setup() {
  wire.begin();
  touch_sensor.setup(wire);

  if (!touch_sensor.communicating()) {
    return;
  }

  touch_sensor.triggerCalibration();
}
#+END_SRC

Legacy sketches can still call =begin()=, which configures the pins and starts
the bus selected in the constructor.

** Typed I2C results

The common driver now records I2C failures and exposes them through
=getLastI2cError()=. The typed result APIs are available from the common base
class for code that needs communication status before using a value.

Current =at42qt::I2cError= values:

- =None=
- =NotInitialized=
- =InvalidKey=
- =DataTooLong=
- =AddressNack=
- =DataNack=
- =OtherBusError=
- =RequestFailed=
- =ShortRead=

* Chip Coverage

- =AT42QT1060=: status, key thresholds, drift and measurement controls, IO and
  mask registers, signal/reference reads, and output-related helpers.
- =AT42QT1070=: status, key thresholds, AKS and integrator settings,
  signal/reference reads, low-power interval, and max-on duration.
- =AT42QT2120=: status, timing controls, slider/wheel configuration,
  per-key control and pulse/scale, signal/reference reads.
- =AT42QT2160=: status, timing controls, per-key thresholds and burst lengths,
  common-change helpers, GPIO wake register, signal/reference reads.

* Compatibility Notes

- =AT42QT1070= and =AT42QT2120= support in this library is for I2C/comms mode.
  Their standalone modes use fixed behavior and are not the target of this API.
- =AT42QT2160= support is based on the revision covered by the datasheet in
  this repository. The datasheet also documents an I2C multi-slave erratum, so
  shared-bus use should be reviewed carefully in hardware designs.

* Validation Notes

- Native tests cover register access helpers and byte-level encode/decode paths.
- PlatformIO example builds were completed in the current environment.
- Hardware revalidation was not completed before this release.

* Bugs Fixed

- Invalid key indices no longer silently map to the last valid key.
- =AT42QT1060::getAdjacentKeySuppressionMask()= now reads the correct register.
- =AT42QT2160::getStatus()= now reads the documented 5-byte status block rather
  than over-reading 8 bytes.
